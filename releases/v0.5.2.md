# RustClipSync Desktop 0.5.2

Fix misleading upgrade prompts when a gateway interrupts clipboard sync.

- Show HTTP 502, 503, 504 and Cloudflare 530 as connection failures. Automatic
  sync retries with backoff and resumes when the server is reachable.
- Reserve the upgrade prompt for explicit protocol incompatibility. When a
  gateway rejects the control WebSocket, the client can fall back to HTTPS.
- Existing pairings work with the current protocol 3 server.

Includes Windows x64 and Linux x86_64 packages for Debian 12, Ubuntu 24.04,
Fedora 43 and Arch, with SHA-256 checksums. The Windows installer is unsigned.
