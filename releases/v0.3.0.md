Windows 与 Linux 的首个统一正式版本，使用相同 Rust 后台和同步核心。

- Windows 11：WinUI 3 界面、托盘、自启、全局快捷键、加密历史及敏感收件小窗。
- Linux：Qt 6/QML 界面、Wayland/X11 剪贴板、Secret Service 加密密钥、敏感收件区及不含正文的桌面通知。
- 同时提供 Debian 12、Ubuntu 24.04、Fedora 43、Arch 的 x86_64 安装包。
- 一次 CI/CD 完成双端构建、原生测试、安装验证和统一发布，附 SHA256SUMS。

从下方选择对应系统安装包。Linux 使用系统 Qt 6，需解锁 Secret Service 密钥环；Wayland 需要 data-control 协议，缺少该协议的 GNOME/Wayland 会话暂不支持。Linux 快捷键通过桌面环境绑定。

“同步已标记的敏感文本”和敏感文本自动写入剪贴板均默认关闭。状态与历史本机加密；HTTPS 保护传输，服务端仍可读取正文。

Windows 安装包当前未签名。完整说明见 [README](https://github.com/Infinifar/rustclipsync-desktop#readme) 与 [Linux 使用说明](https://github.com/Infinifar/rustclipsync-desktop/blob/main/LINUX.md)。
