Windows 精简安装包与共享运行库支持。

- Windows 使用系统 .NET 10 Runtime 与 Windows App Runtime 2.6.4 x64，移除随包的 .NET、WinUI 原生运行库及未使用的 AI/ONNX/DirectML 组件。
- 缺少运行库时显示微软原生下载提示；安装完成页提供两个官方下载按钮，开始菜单附离线可读的运行环境说明。
- 安装时清理程序目录内的旧运行库，配对、加密状态和历史数据仍保存在独立数据目录。
- 增加缺失依赖提示、微软运行库签名与安装、中文安装器下载按钮和程序功能的原生验证，并限制安装器体积不超过 20 MiB。
- Linux 同步更新版本信息，四种发行版安装包一同构建并执行回归检查。

Windows 11 不保证预装指定运行库。已有兼容版本可直接复用；首次补齐依赖需要额外下载，运行库占用不包含在客户端安装包内。应用不会在后台执行依赖安装器。

本次主要精简分发体积。页面按需创建、最小化暂停刷新及历史刷新优化安排在后续阶段；不将安装包缩小比例作为内存收益。

Windows 安装包仍未签名。详见 [Windows 安装说明](https://github.com/Infinifar/rustclipsync-desktop/blob/main/WINDOWS.md)。
