Synchronization reliability fixes for Windows and Linux.

- Apply updated upload filters to pending content before sending, including content queued while offline.
- Supersede old pending text when a newer copy exceeds the size limit; resolve uncertain uploads before discarding them.
- Check restored pending content against the current clipboard before sending after a restart.
- Keep loop suppression active after slow downloads, and recover ambiguous clipboard writes as skipped so later receives can continue without replaying the write.
- Retain connection-state notifications when the notification queue is full.

The shared core also provides standard error chains and explicit worker shutdown/join APIs. Existing device pairing and encrypted state remain compatible.

This release includes the Windows x64 installer and Linux x86_64 packages for Debian 12, Ubuntu 24.04, Fedora 43 and Arch. Windows uses the existing shared-runtime installer and remains unsigned.
