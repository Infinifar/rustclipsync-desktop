Windows 运行时资源优化，Windows 与 Linux 同步发布。

- Windows 启动只创建主页；外观、快捷键、设置和主页历史在首次打开时创建，随后复用并保留页面状态。
- 主窗最小化或隐藏时暂停状态刷新，恢复后立即刷新；Rust 后台继续同步，敏感收件小窗独立更新。
- 历史按存储实例、修订号和查询条件缓存，无变化时不重复读取或重建列表；分页只生成当前页预览，复制只读取所选条目，无变化清理避免克隆整份历史。
- Linux 同步处理历史存储实例变更，避免后台重启后误用相同修订号的旧缓存；提供 Ubuntu 24.04、Debian 12、Fedora 43 和 Arch x86_64 安装包。
- 增加原生界面的按需创建、最小化暂停、恢复刷新、分页、搜索和收藏回归验证。

16 MiB 合成历史的分页读取约分配 36 KB，连续 100 次无变化清理分配为 0。该结果衡量分配量，不代表常驻内存降幅，详见 [验证记录](https://github.com/Infinifar/rustclipsync-desktop/blob/main/VALIDATION.md)。

Windows 安装包继续使用系统共享 .NET 10 Runtime 与 Windows App Runtime 2.6.4 x64，缺少依赖时提供官方下载入口。Windows 安装包仍未签名，详见 [安装说明](https://github.com/Infinifar/rustclipsync-desktop/blob/main/WINDOWS.md)。
